ПРОЕКТ: АВТОСАЛОН

1. ОПИСАНИЕ
Проектът представлява проста програма за управление на автосалон.
Тя позволява добавяне, показване, търсене и сортиране на автомобили
според тяхната цена.

2. ФАЙЛОВЕ
models.py - съдържа класа Avtosalon и неговите методи.
main.py - стартира програмата и показва меню за работа.
requirements.txt - описва необходимостта от библиотеки.
readme.txt - съдържа описание и инструкции за проекта.

3. ИЗПОЛЗВАНИ ТЕХНОЛОГИИ
Програмата е написана на Python 3.
Използвани са класове, обекти, методи, списъци, цикли и условни оператори.

4. СТАРТИРАНЕ
Необходимо е да имате инсталиран Python 3.
Отворете терминал в папката на проекта и изпълнете:

python3 main.py

5. ИНСТРУКЦИИ ЗА РАБОТА
При стартиране се появява меню с пет опции:
1 - показва всички автомобили.
2 - добавя нов автомобил.
3 - търси автомобил по марка.
4 - подрежда автомобилите по цена във възходящ ред.
5 - приключва програмата.

6. БИБЛИОТЕКИ
Не са използвани външни библиотеки. Програмата работи със стандартните
възможности на Python 3.
